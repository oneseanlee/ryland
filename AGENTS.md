# Architecture rules
- Unpaid inquiry cleanup uses an owner/admin-checked RPC with payment protection and audit history; cancelled orders leave active lists while documents and invoice records remain intact.
- Inquiry reads use session-scoped React Query keys; database row policies remain the authority for access, allowing reads to start without waiting for an affiliate profile.
- Admin inquiry documents load per opened order, and cached inquiry lists stay visible during refreshes to avoid blocking navigation on unrelated data.
- Inquiry accounts without affiliate profiles use a bounded loading fallback; admins navigate to the guarded admin inquiry route rather than waiting for a partner record they do not need.
- Inquiry submission delivery runs in a separate authenticated function after checkout via EdgeRuntime.waitUntil; per-order checkpoints and leases support admin retries without repeating completed steps or blocking payment navigation.
- Inquiry document copies go to the GoHighLevel contact file field via the documented upload-custom-files endpoint (user accepted that GHL file links open without sign-in); originals stay in private storage. The shared helper sends the owner's full set in one request when new files exist and verifies the contact's file count before marking new rows, because uploads replace the field. Post-submission attachments use push-lead-documents; undelivered inquiries defer to delivery.
- Late inquiry document pushes use the shared upload result's newly-added count and saved initial Slack timestamp for best-effort thread replies, so Slack failures never fail a verified document upload.
